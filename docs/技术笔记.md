# 固件技术笔记（V1.26）

从早期研究 README 中保留的、对后续修改仍有用的定位信息。需要更多细节时，可以用 Capstone 反汇编原版固件。

| 项目 | 位置/含义 |
|---|---|
| 芯片 | INGCHIPS ING91680C，升级头标识 `HS_KB_WH_V01` |
| 应用装载地址 | 0x02027000，镜像前 128 字节是升级头 |
| 实体 Fn 键 | 原始矩阵位置 90，指令 `50 02 00` |
| 键事件分发 | 0x02041EA4 |
| 特殊键处理 | 0x020343EC（补丁在此入口替换 4 字节作为钩子） |
| 原 Fn 分支 | 0x0203459A |
| 原媒体键处理 | 0x02033EA4；r0=Usage 低字节，r1=高字节，r2=按下/释放 |
| Mac/Win 标志 | RAM 0x200077A1；Hub 字段 macWin，0 为 Win，非零为 Mac |
| 原 Fn 按住计数 | RAM 0x200095AB |
| 媒体键报告 | RAM 0x20008533..0x20008534，同时只能容纳一个 Usage |
| 新代码位置 | 0x02050F30，位于原末尾扇区内，不分配新 RAM |

升级包校验：头部 0x3E 为 payload CRC，0x7E 为 header CRC，均为 CRC16/MODBUS（初值 FFFF，多项式 A001），大端存储；长度位于 0x6E（小端）。已用 V1.26 与 V1.06 原包交叉复算。

## 升级协议

`工具/flash_yogo.py` 按 ATK HUB Beta 3.2.6 的升级协议实现（SWITCH_BOOT / START / FLASH_WRITE / SWITCH_APP，56 字节分包，BCC 和 CRC16），输出包与 Hub 逐字节一致。
